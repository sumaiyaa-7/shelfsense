ShelfSense

A multi-agent AI copilot for retail store teams. Ask about store policies, sales, or inventory.

A router sends each question to a policy agent (searches store policy documents and cites sources) or a data agent (writes a safe, read-only SQL query against sales and inventory data), or to both. This demo uses synthetic data for a fictional retailer and runs in offline mode. See the code on GitHub.
